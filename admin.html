¿Cómo gestionar y actualizar tu sitio web?

Este panel te permite gestionar dinámicamente todo el contenido de la web institucional (textos, descripciones, teléfonos de contacto, catálogo de herramientas y transiciones de diseño). Los cambios que realices se guardan en vivo y pueden sincronizarse a la nube con un solo clic.

Paso 1
Edita el Contenido
Agrega o edita productos, marcas oficiales o personaliza la estética (colores, degradés y botones) en el menú lateral.
Paso 2
Previsualiza los cambios
Usa el botón "Ver Sitio en Vivo" para revisar cómo queda el sitio con tus cambios aplicados al instante.
Paso 3
Publica en Producción
Presiona "Publicar Cambios" para sincronizar la base de datos de Supabase y activar el despliegue en Vercel.

¿Cómo conseguir mi ID de medición?

  1. Ve a tu panel de Google Analytics.
  2. Crea o selecciona una Propiedad de Google Analytics 4 (GA4).
  3. Dirígete a Administrar > Flujo de datos y selecciona tu flujo web.
  4. Copia el ID de medición (comienza con "G-") e ingrésalo arriba.

Sincronización Automática con Vercel (Deploy Hook)

Ingresa tu URL de Deploy Hook de Vercel. Cada vez que presiones "Publicar en Supabase", el panel enviará automáticamente una señal a Vercel para reconstruir y publicar los archivos estáticos en la nube.

¿Cómo aplicar estos cambios en producción de forma definitiva?

1

Haz clic en el botón de arriba "Descargar data.json" para descargar el archivo de datos actualizado.

2

Busca el archivo en tu computadora y muévelo dentro de la carpeta del proyecto en la ruta: assets/data.json (esto reemplazará el archivo viejo con tus textos y productos nuevos).

3

Si estás compilando la web localmente, ejecuta el comando npm run build en la terminal para que se generen los archivos listos para producción. ¡Listo! Al subir la web los clientes verán los datos actualizados de forma permanente.

Cambiar Contraseña Administrativa
