¿Cómo gestionar y actualizar tu sitio web?

Este panel te permite gestionar dinámicamente todo el contenido de la web institucional (textos, descripciones, teléfonos de contacto y productos de catálogo). Los cambios que realices se guardan inmediatamente en tu navegador actual para que puedas previsualizarlos en vivo.

Paso 1
Edita el Contenido
Agrega o edita productos, o modifica los textos principales en el menú lateral.
Paso 2
Previsualiza los cambios
Usa el botón "Vista Previa Web" para revisar cómo queda el sitio con tus cambios aplicados.
Paso 3
Exporta la Configuración
Ve a "Guardar y Exportar", descarga el archivo data.json y colócalo en el código para subirlo.

¿Cómo conseguir mi ID de medición?

  1. Ve a tu panel de Google Analytics.
  2. Crea o selecciona una Propiedad de Google Analytics 4 (GA4).
  3. Dirígete a Administrar > Flujo de datos y selecciona tu flujo web.
  4. Copia el ID de medición (comienza con "G-") e ingrésalo arriba.
Archivo de Datos Generado (data.json)

¿Cómo aplicar estos cambios en producción de forma definitiva?

1

Haz clic en el botón de arriba "Descargar data.json" para descargar el archivo de datos actualizado.

2

Busca el archivo en tu computadora y muévelo dentro de la carpeta del proyecto en la ruta: assets/data.json (esto reemplazará el archivo viejo con tus textos y productos nuevos).

3

Si estás compilando la web localmente, ejecuta el comando npm run build en la terminal para que se generen los archivos listos para producción. ¡Listo! Al subir la web los clientes verán los datos actualizados de forma permanente.
